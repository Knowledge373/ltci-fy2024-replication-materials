# 2024年度 介護保険料普通徴収の納期一覧と再計算資料

全国1,573保険者について、2024年度の通常納期を月別に確認できます。仮算定の有無は、2024年度の通常の普通徴収について、条例等と必要に応じた個別照会に基づき判定した。

- [島嶼を含む仮算定の全国図](NATIONAL-MAP-JA.md)
